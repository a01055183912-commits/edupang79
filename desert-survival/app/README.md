# 사막 생존 게임 웹앱 (중구도시관리공단 워크숍)

참가자 휴대폰으로 접속해 **개인 순위 → 팀 합의 순위 → 점수·팀별 순위**까지 진행하는 웹앱입니다. 의존성이 없는 Node 서버 하나로 동작합니다(Node 18 이상).

## 실행
```bash
cd desert-survival/app
ADMIN_PIN=원하는숫자 npm start      # 기본 포트 8081. PIN을 안 주면 실행할 때마다 무작위 PIN을 로그에 출력
```
- 참가자: `http://서버주소:8081/` / 진행자: `http://서버주소:8081/#admin` (PIN 입력)
- 같은 와이파이의 휴대폰이 접속하려면 서버 컴퓨터의 IP 주소를 쓰세요. 인터넷에 올리려면 Railway 등에서 이 폴더(`desert-survival/app`)를 루트로 두고 시작 명령 `npm start`, 환경변수 `ADMIN_PIN`을 설정하세요.
- 상태는 `data/state.json`에 저장됩니다. 클라우드 호스팅에서는 재시작 시 사라질 수 있으니 행사 중에는 재배포하지 마세요.
- 테스트: `npm test` (점수·반영도 계산 9건)

## Railway 배포
1. Railway에서 **New Project → Deploy from GitHub repo**로 이 저장소를 고릅니다. 브랜치는 이 앱이 들어 있는 브랜치(또는 병합한 `main`)로 지정합니다.
2. 서비스 **Settings → Source → Root Directory**를 `desert-survival/app`으로 바꿉니다(저장소 루트에는 다른 앱의 `server.mjs`가 있어서 반드시 필요합니다).
3. **Variables**에 `ADMIN_PIN`(진행자 PIN, 숫자 6자리 이상 권장)을 추가합니다. 필요하면 `TEAM_COUNT`(기본 5), `TEAM_SIZE`(기본 6)도 넣습니다.
4. **Settings → Networking → Generate Domain**으로 공개 주소를 만듭니다. 이 주소(`https://….up.railway.app`)로 진행자 화면(`/#admin`)을 열면 QR 코드가 이 주소로 자동 생성됩니다.
5. (선택) 재시작해도 입력을 보존하려면 **Volume**을 `/data`에 붙이고 `DATA_DIR=/data`를 추가합니다. 행사 중에는 재배포하지 마세요.

`railway.json`이 시작 명령(`npm start`)과 헬스체크(`/api/lobby`)를 지정합니다. 서버는 Railway가 주는 `PORT`를 자동으로 사용합니다.

## 팀 구성과 QR 접속 (5팀 × 6명 기본값)
- 진행자 화면(`#admin`)의 **팀 구성**에서 팀 수(1~10)와 팀당 최대 인원(1~20)을 바꿀 수 있습니다. 기본값은 5팀·6명이며, 서버를 켤 때 환경변수 `TEAM_COUNT`, `TEAM_SIZE`로도 정할 수 있습니다. 정원이 찬 팀은 입장 화면에서 선택할 수 없습니다.
- **팀 이름:** 팀원 누구나 화면에서 정할 수 있고(마지막 저장이 반영), 진행자가 고칠 수도 있습니다. 비워 두면 사막 동물 이름이 쓰입니다.
- **QR 코드:** 진행자 화면에서 ① 전체 접속 QR, ② 화면 공유용 크게 보기, ③ 팀별 QR 인쇄(테이블마다 한 장, 찍으면 그 팀이 미리 선택)를 만듭니다. QR은 앱에 포함된 생성기(`public/vendor/qrcode.js`, MIT)로 만들어 인터넷 없이도 동작합니다.
- 휴대폰이 열 수 있는 주소여야 합니다. 같은 와이파이를 쓸 때는 진행자 화면에 보이는 컴퓨터의 주소(예: `http://192.168.0.10:8081`)를 눌러 QR을 바꾸세요. `localhost`로 만든 QR은 휴대폰에서 열리지 않습니다.

## 진행 순서
| 단계 | 참가자 화면 | 진행자 |
|---|---|---|
| 입장 | 이름 + 팀 번호(1~10) 선택. 같은 이름·팀으로 다시 들어오면 이어서 진행 | |
| 1단계 혼자 정하기 | 15가지 물건을 ▲▼로 1~15위 정렬, “왜 1위로 했나요?” 한 줄 입력 후 제출 | 제출 현황(초록색 = 제출 완료) 확인 |
| 2단계 팀이 하나로 | **의견이 가장 갈린 물건** 3개를 보여 주고, 팀원 순위 평균을 시작 순서로 제공. 기록 담당이 팀 순위 제출, “조용하거나 막내 팀원 의견으로 바뀐 순위” 체크·메모 | 팀별 발언 인원 선택, 소수 의견 채택 확인 |
| 3단계 결과 | 팀별 순위·점수(구성 막대), 내 개인 오차점수, 전문가 정답과 이유 | 단계 버튼으로 공개 시점 결정 |
| 4단계 우리 팀 이야기 | **① 내 의견은 얼마나 담겼을까?**(자동 계산) → **② 탐험대 셀프 체크**(이모지 5문항) → **③ 팀 이야기 만들기**(위기·반전·결말) → **④ 팀 이야기 카드**(설문이 익명으로 모임) | 팀별 설문 참여 현황, 발표용 이야기 카드 |

결과는 진행자가 3단계로 넘기기 전에는 서버가 내려주지 않습니다. 단계가 맞지 않는 제출(예: 개인 단계에 팀 제출)은 거부됩니다.

## 재미 요소와 이미지
- 입장할 때 팀마다 사막 마스코트(🐪낙타 🌵선인장 🦂전갈 🦎도마뱀 🦅독수리 🐍방울뱀 🦊사막여우 🐢거북이 🌴오아시스 ☀️태양)가 정해지고, 화면 곳곳에 팀 이름과 함께 표시됩니다.
- 위쪽 단계 표시줄(🤫혼자 → 🗣️팀 → 🚁결과), 단계별 일러스트와 한 줄 안내, 물건 15가지 그림 카드, 제출할 때 폭죽, 제출 후 모래시계 대기 화면, 결과의 시상대(🥇🥈🥉)와 점수대별 한마디가 들어 있습니다. 움직임 줄이기 설정을 켠 기기에서는 폭죽·애니메이션을 끕니다.
- 그림은 원본 PPT(`사막 생존 게임`)의 일러스트에서 글자와 워터마크를 피해 잘라 `public/img/`에 넣은 것입니다. 이미지를 바꾸려면 같은 파일 이름으로 교체하세요(물건 그림은 `item-물건id.jpg`, 물건 id는 `items.mjs`).

## 4단계 피드백의 기준
- **의견 반영도(%)** = `100 × (1 − Σ|내 순위 − 팀 순위| / 112)`. 내 개인 순위가 팀 합의 순위와 같으면 100%, 완전히 반대면 0%입니다. 점수가 아니라 **대화를 여는 참고값**이며, 개인 값은 본인에게만 보입니다(팀 카드에는 평균과 편차만 표시).
- **“느낌 vs 실제”:** 설문 3번(의견이 반영됐다고 느낀다, 1~5점)과 반영도를 비교해 4~5점이면서 65% 이상이면 “든든”, 4~5점인데 65% 미만이면 “서로 충분히 들었나?”, 1~2점이면서 65% 미만이면 “서운했을 수 있어요”, 1~2점인데 65% 이상이면 “생각보다 많이 담겼어요”로 안내합니다. 65%는 이 앱이 정한 값입니다(무작위 순위의 평균 반영도는 약 33%).
- 설문 5문항: 끝까지 말하기, 끝까지 듣기, 내 의견 반영, 설득·양보(각 1~5점), 대화 분위기 날씨. 선택 항목으로 “오늘 우리 팀을 살린 한마디”(익명으로 팀 카드에 표시)와 “내일 일터에서 해볼 한 가지”(최대 2개)가 있습니다.
- 팀 평균 반영도의 최고·최저 차이가 30%p 이상이면 “목소리가 작게 담긴 사람은 없었는지” 이야기해 보도록 카드에 안내합니다.

## 점수 (100점)
정답 순위와의 차이 `|내 순위 − 정답 순위|`를 15개 더한 값이 **오차점수**(낮을수록 좋음, 최악 112)입니다.

| 항목 | 배점 | 계산 |
|---|---|---|
| 팀 정확도 | 40 | `40 × (1 − 팀 오차 / 60)` (60 이상이면 0) |
| 시너지 | 30 | `(개인 평균 오차 − 팀 오차) × 1.5` (최대 20) + 팀 오차가 팀 내 최고 개인보다 낮으면 +10, 합계 최대 30 |
| 참여도 | 30 | 전원 발언 15(발언 안 한 팀원 1명당 −3, 진행자가 입력) + 소수 의견 채택 15(팀이 체크, 진행자가 수정 가능) |

- 개인 순위를 제출한 팀원만 개인 평균·최고에 포함됩니다.
- 발언 인원을 입력하기 전에는 전원 발언 점수가 0점이며 “참여도 미평가”로 표시됩니다.
- 정답 순서와 이유는 `items.mjs`, 점수 공식은 `scoring.mjs`에 있습니다. 정답 순위는 원본 PPT 기준이며, 실제 교육 전 안전 검수를 받으세요.

## 알아둘 점
- 로그인 없이 이름·팀으로만 입장하는 현장용 도구입니다. 진행자 기능만 PIN으로 보호하며, PIN 실패가 1분에 20번을 넘으면 잠시 차단합니다.
- 이름은 최대 20자, 최대 200명까지 받습니다.
