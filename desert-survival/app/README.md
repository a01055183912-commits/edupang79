# 사막 생존 게임 웹앱 (중구도시관리공단 워크숍)

참가자 휴대폰으로 접속해 **개인 순위 → 팀 합의 순위 → 점수·팀별 순위**까지 진행하는 웹앱입니다. 의존성이 없는 Node 서버 하나로 동작합니다(Node 18 이상).

## 실행
```bash
cd desert-survival/app
ADMIN_PIN=원하는숫자 npm start      # 기본 포트 8081. PIN을 안 주면 실행할 때마다 무작위 PIN을 로그에 출력
```
- 참가자: `http://서버주소:8081/` / 진행자: `http://서버주소:8081/#admin` (PIN 입력)
- 같은 와이파이의 휴대폰이 접속하려면 서버 컴퓨터의 IP 주소를 쓰세요. 인터넷에 올리려면 Railway 등에서 이 폴더(`desert-survival/app`)를 루트로 두고 시작 명령 `npm start`, 환경변수 `ADMIN_PIN`을 설정하세요.
- 상태는 `data/state.json`에 저장됩니다. 클라우드 호스팅에서는 재시작 시 사라질 수 있으니 행사 중에는 재배포하지 마세요.
- 테스트: `npm test` (점수 계산 7건)

## 진행 순서
| 단계 | 참가자 화면 | 진행자 |
|---|---|---|
| 입장 | 이름 + 팀 번호(1~10) 선택. 같은 이름·팀으로 다시 들어오면 이어서 진행 | |
| 1단계 혼자 정하기 | 15가지 물건을 ▲▼로 1~15위 정렬, “왜 1위로 했나요?” 한 줄 입력 후 제출 | 제출 현황(초록색 = 제출 완료) 확인 |
| 2단계 팀이 하나로 | **의견이 가장 갈린 물건** 3개를 보여 주고, 팀원 순위 평균을 시작 순서로 제공. 기록 담당이 팀 순위 제출, “조용하거나 막내 팀원 의견으로 바뀐 순위” 체크·메모 | 팀별 발언 인원 선택, 소수 의견 채택 확인 |
| 3단계 결과 | 팀별 순위·점수(구성 막대), 내 개인 오차점수, 전문가 정답과 이유 | 단계 버튼으로 공개 시점 결정 |

결과는 진행자가 3단계로 넘기기 전에는 서버가 내려주지 않습니다. 단계가 맞지 않는 제출(예: 개인 단계에 팀 제출)은 거부됩니다.

## 재미 요소와 이미지
- 입장할 때 팀마다 사막 마스코트(🐪낙타 🌵선인장 🦂전갈 🦎도마뱀 🦅독수리 🐍방울뱀 🦊사막여우 🐢거북이 🌴오아시스 ☀️태양)가 정해지고, 화면 곳곳에 팀 이름과 함께 표시됩니다.
- 위쪽 단계 표시줄(🤫혼자 → 🗣️팀 → 🚁결과), 단계별 일러스트와 한 줄 안내, 물건 15가지 그림 카드, 제출할 때 폭죽, 제출 후 모래시계 대기 화면, 결과의 시상대(🥇🥈🥉)와 점수대별 한마디가 들어 있습니다. 움직임 줄이기 설정을 켠 기기에서는 폭죽·애니메이션을 끕니다.
- 그림은 원본 PPT(`사막 생존 게임`)의 일러스트에서 글자와 워터마크를 피해 잘라 `public/img/`에 넣은 것입니다. 이미지를 바꾸려면 같은 파일 이름으로 교체하세요(물건 그림은 `item-물건id.jpg`, 물건 id는 `items.mjs`).

## 점수 (100점)
정답 순위와의 차이 `|내 순위 − 정답 순위|`를 15개 더한 값이 **오차점수**(낮을수록 좋음, 최악 112)입니다.

| 항목 | 배점 | 계산 |
|---|---|---|
| 팀 정확도 | 40 | `40 × (1 − 팀 오차 / 60)` (60 이상이면 0) |
| 시너지 | 30 | `(개인 평균 오차 − 팀 오차) × 1.5` (최대 20) + 팀 오차가 팀 내 최고 개인보다 낮으면 +10, 합계 최대 30 |
| 참여도 | 30 | 전원 발언 15(발언 안 한 팀원 1명당 −3, 진행자가 입력) + 소수 의견 채택 15(팀이 체크, 진행자가 수정 가능) |

- 개인 순위를 제출한 팀원만 개인 평균·최고에 포함됩니다.
- 발언 인원을 입력하기 전에는 전원 발언 점수가 0점이며 “참여도 미평가”로 표시됩니다.
- 정답 순서와 이유는 `items.mjs`, 점수 공식은 `scoring.mjs`에 있습니다. 정답 순위는 원본 PPT 기준이며, 실제 교육 전 안전 검수를 받으세요.

## 알아둘 점
- 로그인 없이 이름·팀으로만 입장하는 현장용 도구입니다. 진행자 기능만 PIN으로 보호하며, PIN 실패가 1분에 20번을 넘으면 잠시 차단합니다.
- 이름은 최대 20자, 최대 200명까지 받습니다.
