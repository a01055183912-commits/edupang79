# 에듀팡파트너즈 정책사업 기획 도구

`index.html` 한 장으로 동작합니다(서버 불필요). 입력값은 브라우저 localStorage에만 저장됩니다.

흐름: 사업 설정 → 과정 편성 → 강사 → 예산 → 공고(D-day) → 제안서 초안(.md) → 데이터 백업

- 과정 카탈로그: 교안 v0.6 「나는 사업주다」 4과정(입문 8h·초급 16h·중급 24h·상급 24h). 중급·상급 단원 시간은 추정값이라 화면에서 수정해야 합니다.
- 강사: 김미연 강사 프로필이 기본 등록되어 있고, 강사 파일은 「강사」 탭에서 CSV/JSON으로 가져옵니다.
- 사업자등록번호·주소·생년월일 등 민감 정보는 파일에 넣지 않았습니다.

## 공고 자동 수집
- `scripts/collect.mjs`가 부산소상공인지원센터·테크노파크·기술창업투자원·정보산업진흥원·창조경제혁신센터·관광기업지원센터·디자인진흥원의 접수 중 공고를 `data/notices.json`에 저장합니다.
- `.github/workflows/collect.yml`이 매일 07:00(KST)에 실행합니다. Actions 탭에서 `collect-notices` → Run workflow로 수동 실행도 됩니다.
- 기관별로 실패해도 나머지는 계속 수집하며, 실패한 기관은 이전 결과를 유지하고 「공고」 탭에 "수집 실패"를 표시합니다.
- 기관을 늘리려면 `SOURCES`에 `{id, name, run}`을 추가하세요. `run`은 `{id,title,program,start,deadline,url}` 배열을 돌려줍니다.
- 수집 결과는 확인용입니다. 접수 기한과 자격은 공고문에서 확인하세요.

## 학습 자료 (study.html)
변호사 강의 「정부지원금, 받는 것보다 ‘지키는 것’이 더 어렵습니다」 교안을 공부용으로 정리했습니다. 레슨(M1~M8, 추가 A~C), 퀴즈 45문항(보기 순서 무작위), 통보서 성격 판별 7문항, 10계명·금지 6가지 암기 카드, 판례 색인, 용어집으로 구성됩니다. 판결 번호와 내용은 교안 표기를 그대로 옮긴 것이며 원문 판결은 확인하지 않았습니다.
