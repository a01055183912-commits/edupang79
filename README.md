# 에듀팡파트너즈 수강생 학습·준비 도구

수강생이 정책사업을 **공부하고 준비하는** 웹 도구입니다. 서버 없이 HTML 파일로 동작하며, 입력한 내용은 각자 기기의 브라우저(localStorage)에만 저장됩니다. 모바일에서 보기 좋게 큰 글자와 하단 탭바로 만들었습니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 내 정보(나의 좌표), 학습 진도, 공고, 정책사업 가이드, Claude 질문, 백업 |
| `study.html` | 정부지원금 사후관리 학습(변호사 강의 교안): 레슨, 퀴즈 45문항, 통보서 판별, 10계명, 판례, 용어 |
| `study-data.js` | 교안 내용 데이터(두 페이지와 학습자료 파일이 함께 사용) |
| `pack.js` | 학습자료를 `.md` 파일 하나로 만들어 내려받고, Claude에 질문하는 기능 |
| `scripts/collect.mjs` | 부산 지원기관 공고 자동 수집 → `data/notices.json` |
| `.github/workflows/collect.yml` | 매일 07:00(KST) 수집 실행 |
| `server.mjs`, `package.json` | Railway 등 서버형 호스팅용 정적 서버(`npm start`) |

## Claude로 질문하기
「Claude」 탭에서 학습자료 파일(`edupang_study_pack.md`)을 내려받아 claude.ai에 올리면, 자료를 근거로 설명·퀴즈·질문 답변을 받을 수 있습니다. 파일에는 가이드, 과정 지도, 레슨 전체, 판례·용어, 연습 문제, 현재 공고 목록이 들어 있습니다.

## 공고 자동 수집
소상공인지원센터, 테크노파크, 기술창업투자원, 정보산업진흥원, 창조경제혁신센터, 관광기업지원센터, 디자인진흥원의 접수 중 공고를 수집합니다. 기관별로 실패해도 나머지는 계속 수집하며, 실패한 기관은 이전 결과를 유지하고 화면에 "수집 실패"를 표시합니다. 경제진흥원은 접속 문제로 수동 등록합니다. 기관을 늘리려면 `SOURCES`에 `{id, name, run}`을 추가하세요.

## 유의사항
- 판결 번호와 내용은 교안 표기를 그대로 옮긴 것이며 원문 판결은 확인하지 않았습니다.
- 수집 공고는 확인용입니다. 접수 기한과 자격은 공고문 원문에서 확인하세요.
- 중급·상급 단원의 시간은 교안에서 확인하지 못한 추정값입니다.
