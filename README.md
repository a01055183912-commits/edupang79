# 에듀팡파트너즈 정책사업 기획 도구

`index.html` 한 장으로 동작합니다(서버 불필요). 입력값은 브라우저 localStorage에만 저장됩니다.

흐름: 사업 설정 → 과정 편성 → 강사 → 예산 → 공고(D-day) → 제안서 초안(.md) → 데이터 백업

- 과정 카탈로그: 교안 v0.6 「나는 사업주다」 4과정(입문 8h·초급 16h·중급 24h·상급 24h). 중급·상급 단원 시간은 추정값이라 화면에서 수정해야 합니다.
- 강사: 김미연 강사 프로필이 기본 등록되어 있고, 강사 파일은 「강사」 탭에서 CSV/JSON으로 가져옵니다.
- 사업자등록번호·주소·생년월일 등 민감 정보는 파일에 넣지 않았습니다.
